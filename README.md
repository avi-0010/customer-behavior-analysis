# Customer Behavior Analysis

## Overview

This project analyzes customer purchasing behavior using SQL, PostgreSQL, Jupyter Notebook, and Power BI. The goal is to uncover insights related to customer spending patterns, product performance, customer retention, subscription behavior, and sales trends.

## Tech Stack

* SQL
* PostgreSQL
* Jupyter Notebook
* Python (Pandas)
* Power BI
* Git & GitHub

---

## Project Workflow

### Data Cleaning

Performed data preprocessing using Jupyter Notebook:

* Handled missing values
* Removed inconsistencies
* Standardized data formats

### SQL Analysis

Conducted business analysis using PostgreSQL:

* Customer segmentation
* Product performance analysis
* Discount usage analysis
* Subscription behavior analysis
* Revenue and purchase trend analysis

## Dashboard Features

Built an interactive Power BI dashboard featuring:

* Revenue Analysis
* Customer Segmentation
* Product Category Performance
* Review Rating Insights
* Interactive Filters & Slicers

## Key Insights

* Repeat customers contributed significantly to revenue.
* Discount usage remained high among premium buyers.
* Product performance varied across categories.
* Subscription rates were higher among repeat customers.
